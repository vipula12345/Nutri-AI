SIH PROJECT OVERVIEW · VERSION 15

AI Nutrition Recommendation System

A software-only personalized nutrition platform that combines nutrition calculations, a dataset-driven KNN-style recommendation engine, dietary and allergy filtering, weekly planning, substitutions and progress analytics.

2. How the Recommendation Model Works

Profile → calorie target → meal target → allergy/diet filtering → nutrient feature vector → cosine similarity → ranking → best food match

Input features

Calories, protein, carbohydrates, fat and fibre are normalized into a nutrition profile for each food.

Similarity

The system compares each eligible food with the target nutrient profile using cosine similarity and ranks the closest matches.

Goal adaptation

Weight-loss recommendations receive a high-fibre preference signal; weight-gain recommendations receive a high-protein preference signal.

Why KNN-style?

It provides explainable nearest-neighbor matching without requiring a Python or scikit-learn runtime on the hosted platform.

3. Core Modules

Personalization

Calculates BMI, BMR, TDEE and an approximate daily calorie target from the user's profile and goal.

Meal Recommendation

Selects breakfast, lunch, snack and dinner from the nutrition dataset using nutrient similarity.

7-Day Planner

Creates a Monday–Sunday meal rotation with daily and weekly nutrition totals.

Smart Substitution

Finds nutritionally similar foods in the same meal category while respecting dietary and allergy filters.

Progress Analytics

Lets users log weight and view baseline, change over time, number of entries and average nutrition score.

Wellness Assistant

A free rule-based assistant answers questions about the generated plan, protein choices and safe alternatives without requiring an external AI API key.

4. Responsible AI & Safety

General wellness guidance only. NutriAI does not diagnose diseases, prescribe treatment or claim clinical certainty. Calorie estimates are approximate.
✓ Diet-aware: recommendations are filtered for vegetarian, vegan or non-vegetarian preferences.
✓ Allergy-aware: configured food-avoidance filters are applied before recommendations and substitutions.
✓ Explainable: recommendations expose the matching approach and nutrition features used.
✓ No medical claims: the assistant is limited to general nutrition and wellness education.

5. Suggested SIH Demo Flow

  1. Open NutriAI and enter a sample user profile.
  2. Select a dietary preference and one or more foods to avoid.
  3. Generate the personalized recommendation.
  4. Show BMI, calorie target, nutrition score and meal-level model matches.
  5. Open the 7-day planner and show weekly nutrition totals.
  6. Use Find similar food to demonstrate safe substitution.
  7. Ask the Wellness Assistant: “How can I increase protein in my meals?”
  8. Log a progress entry and show the analytics section.
